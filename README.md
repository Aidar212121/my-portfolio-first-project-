# Игра «Камень-Ножницы-Бумага» на Python

Контрольная работа: консольная игра «Камень-Ножницы-Бумага», в которой игрок соревнуется против компьютера до 3 побед (очков).

---

## 📌 Описание проекта

Программа представляет собой классическую игру «Камень-Ножницы-Бумага». Выбор компьютера генерируется случайно, а игрок вводит свой вариант через консоль. Игра ведется до тех пор, пока один из участников не наберет **3 очка**.

### 🎮 Игровой процесс и правила
* **Камень** бьет **ножницы**.
* **Ножницы** бьют **бумагу**.
* **Бумага** бьет **камень**.
* При одинаковом выборе объявляется **ничья**, и баллы никому не начисляются.
* После каждого раунда выводится выбор компьютера и текущий счет.

---

## 🛠 Особенности реализации

Код структурирован и разбиты на функции согласно требованиям:

* `get_computer_choice()` — случайно выбирает один из вариантов (`"камень"`, `"ножницы"`, `"бумага"`) для компьютера.
* `determine_winner(player, computer)` — сравнивает выбор игрока и компьютера и определяет победителя раунда (`"draw"`, `"player"`, `"computer"`).
* `main()` — содержит основную логику:
  * Приветствие игрока и вывод правил.
  * Игровой цикл с проверкой корректности ввода.
  * Ведение счета и вывод результатов каждого раунда.
  * Объявление финального победителя по достижении 3 очков.
